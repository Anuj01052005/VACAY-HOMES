# Approved direction

The user selected **Option B — The residence journal**, then requested stronger cinematic animation. The natural morning edit was explicitly approved. The WhatsApp field is intentionally blank and editable.

## Visual system

Plum ink `#3C253C`, porcelain `#F9FAFB`, cool mist `#EEF2F4`, sage `#C4CFBF`, stone `#A99B7B`. Bodoni Moda is the display face and DM Sans carries body text and controls. Asymmetric photography, one architectural curve, restrained type and generous space follow the spirit of the supplied ERA guide without copying its layout.

## Journey and feeling

1. Recognition: the full property name is visible immediately beside real aerial footage.
2. Anticipation: the frame expands while the title recedes, bringing the visitor into the landscape.
3. Arrival: the approved morning entrance photograph replaces the aerial, preserving a clear cut between actual viewpoints.
4. Release: the pool scene rises into view. This is the tour's visual peak.
5. Comfort: living room and bedroom photographs become compact, calm editorial spreads.
6. Warmth: genuine night gazebo footage changes the pace before the inquiry.

The memorable move is the split editorial opening becoming a full-screen arrival sequence. The architecture remains photographic; there is no fabricated 3D villa or simulated continuous camera flight through the gate.

## Motion score

| Beat | Treatment | Purpose |
| --- | --- | --- |
| Opening | Live aerial within asymmetric frame | Immediate property evidence and movement |
| Aerial expansion | Scroll-controlled frame reveal; independent title and control planes | Move from editorial overview into the property |
| Entrance | Crossfade and restrained photographic scale | Convey arrival without pretending the photo is footage |
| Pool | Upward scene reveal over the entrance | Open the view onto the grounds |
| Rooms | Asymmetric normal-flow images and restrained differential travel | Let visitors inspect the actual interiors |
| Evening | Natural-scroll scale with genuine night film | Contrast daylight with the real gazebo atmosphere |
| Inquiry | Static, legible closing | Keep the next action clear |

Mobile uses a shorter natural-flow version with opt-in short films. Reduced motion removes camera-scale motion, pinning and automatic media while preserving every image and section.

## Component research

21st catalog exploration included cinematic heroes, media expansion, morphing heroes and image galleries. Public pages reviewed:

- https://21st.dev/@jahed/components/cinematic-landing-hero
- https://21st.dev/@jean.duthil13/components/hero-scrub
- https://21st.dev/@prashantsom75/components/scroll-morph-hero
- https://mcp.21st.dev/@daiwiikharihar/components/elastic-gallery

CLI retrieval required sign-in. No catalog component source was copied. The implementation uses local vanilla JavaScript and GSAP to match the project's existing stack. Generic rainbow morphing, domino effects, hover-only accordion galleries and extra React dependencies were rejected as unsuitable for this property tour.

## Content constraints

Only the supplied property media is used, except for the explicitly approved entrance-lighting edit. No stock footage, invented reviews, prices, discounts, availability, capacity or amenity claims. Decorative setups visible in original photographs are not sold as an included package. Seasonal messaging stays off until confirmed.
